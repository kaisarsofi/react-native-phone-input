# react-native-phone-input

Customizable phone number input with country picker and validation for React Native & Expo (no native dependencies, web-compatible)

## Installation


```sh
npm install react-native-phone-input
```


## Usage


```js
import { COUNTRIES, getCountryByCode } from 'react-native-phone-input';

// ...

const us = getCountryByCode('US');
```
